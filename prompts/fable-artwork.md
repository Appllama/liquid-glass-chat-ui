# Cookbook 1 (Fable): artwork

The selected story prompts below come from the source project. They were recorded with GPT Image 2.5 via Higgsfield, high quality, 1K, 9:16. Keep the bundled filenames if replacing assets. Export stories as 752 x 1344 JPEGs; all assets load locally.

## Portrait replacement recipe

The exact portrait generation prompts were not retained with the source. This is a replacement recipe, not an exact reconstruction:

```text
Create a square candid head-and-shoulders portrait of a fictional adult. Natural expression, soft window light, a quiet warm-neutral background, realistic skin texture, distinct age, hair, and clothing. Face centered with generous circular-crop safety. No text, logos, frame, or watermark.
```

Use a consistent visual style across the 14 portraits. The team avatar is a pale sculptural glass orb.
